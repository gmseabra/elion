Vina objective · drives the search

The search minimizes the full Vina ΔG below — five distance-dependent terms over every ligand↔receptor heavy-atom pair within 8 Å, divided by the Nrot penalty. Every weight is editable and re-derives the search; the breakdown tracks the current pose. Lower ΔG = better.

Vina weights · editable

c = Σpairs [
· e−(s/0.5)²gauss₁
· e−((s−3)/2)²gauss₂
· s²·[s<0]repulsion
· hydrophobic(s)hphob
· Hbond(s)H-bond
]
ΔG = c ∕ (1 + · Nrot)

s = r − Ri − Rj (surface gap, XS radii) · hydrophobic ramps 1→0 over s = 0.5…1.5 Å on hydrophobic–hydrophobic pairs · H-bond ramps 1→0 over s = −0.7…0 Å on donor–acceptor pairs · 8 Å cutoff. Edit any weight to retune the search. Lower ΔG = stronger binding.

Each step (monte_carlo.cpp): mutate_conf one of (2 + ntorsions) entities → BFGS local-minimise → Metropolis accept.

BFGS is real: analytic Cartesian forces are projected onto the torsion tree (force sum → translation, torque about the rotation centre → orientation, per-torsion torque along its own axis), with an inverse-Hessian update and an Armijo backtracking line search (bfgs.h, fixed): c₀=1e-4 · backtrack ×0.5 · ≤10 trials · converge ‖∇E‖<1e-5.

Intramolecular energy · ligand internal

eintra = Σintra pairs curl( VVina(s), v )  ·  curl(e,v) = e·v ∕ (v+e) for e>0

The engine now builds Vina's real pair set (model.cpp:535-560): pairs whose distance can actually change (mobility == DISTANCE_VARIABLE) and that are more than 3 bonds apart — 1-2, 1-3 and 1-4 all excluded, same rigid fragment excluded — scored with all five terms, not repulsion alone. It is subtracted as Vina does (inter + intra − intra_energy(best pose), vina.cpp:727), so it shapes the minimised pose and cancels in the reported ΔG. No weight knob: it is part of the objective, not an add-on.

Calibration · reconcile with the Vina binary

Nrot

Vina divides c by (1 + 0.05846·Nrot). auto now reproduces conf_independent.cpp:86-109 exactly — 0.5 per rotatable bond per heavy endpoint, terminal groups (CH₃ etc.) skipped — so it lands on the same half-integer the binary logs. rigid keeps Nrot=0. manual uses the box above.

atom typing

Vina 1.2.7 is the faithful path: donor/acceptor resolved from residue+atom chemistry on the receptor and from the bond graph plus implicit-H valence on the ligand (so xs_h_bond_possible really needs a donor and an acceptor), C_P from the bond graph, halogens hydrophobic, metals as Met_D (r = 1.2 Å, donor). The legacy modes treat every N and O as simultaneously donor and acceptor, which pays full H-bond reward on acceptor–acceptor pairs Vina scores as zero — worth roughly +2.5 kcal/mol of spurious binding on a polar ligand. They are kept only so the difference stays visible.
